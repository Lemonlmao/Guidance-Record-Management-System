Developed a standalone Java and SQL application for creating, organizing, and tracking student guidance records. Features include student profiles, case notes, follow-up tracking, appointment scheduling, reports, CSV exports, and SQL backups.

Added owner authentication, password hashing, server-side validation, prepared SQL statements, and a tamper-evident audit trail to support data integrity. Built a browser interface using HTML, CSS, and JavaScript and tested the application with fictional student data.
